# SUNSET-Site-lanchonete

Projeto acadêmico de uma página de lanchonete, criado durante o terceiro semestre do curso de Sistemas de Informação.

## Estado atual

O repositório contém uma página estática construída com:

- HTML;
- CSS;
- JavaScript;
- Bootstrap;
- imagens locais de produtos.

O ponto de entrada é o arquivo `index.html`.

## Estrutura principal

- `index.html`: página inicial;
- `css/`: Bootstrap e estilos do projeto;
- `js/`: Bootstrap e scripts do projeto;
- `img/`: imagens utilizadas na página;
- `AGENTS.md`: regras para agentes e padrão de documentação dos commits.

## Executar localmente

Abra `index.html` em um navegador. O projeto não possui servidor ou processo de compilação documentado.
